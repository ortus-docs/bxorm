BxORM maps BoxLang classes to database tables. This course takes you from an empty folder to a small blog (users, posts and tags) running on BxORM, one short lesson at a time. Each lesson builds on the one before it and ends with a **Try it** section.

Your progress is remembered in this browser, so you can stop and pick up where you left off.

::: course id="learn-bxorm" :::

## Before you start

You need:

- [BoxLang](https://boxlang.io) 1.x installed, with the `boxlang` and `bx-module` commands on your path.
- A database you can create tables in. The lessons use MySQL, and every other database Hibernate supports works the same way.
- A little BoxLang: variables, functions and classes.

The first twelve lessons are **the essentials**. Lessons 13 to 17 **go further**: inheritance, testing, cborm, building with AI and moving an existing CFML app. Take those in any order.

Every lesson links to the full [BxORM documentation](https://bxorm.ortusbooks.com/bxorm-2.x/) for the details it leaves out.
