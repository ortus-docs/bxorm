# Function: `EntityGetDirtyProperties`

The names of an entity's properties whose values differ from the stored ones.

## Method Signature

```
EntityGetDirtyProperties(entity=[Any])
```

### Arguments


| Argument | Type | Required | Description | Default |
|----------|------|----------|-------------|---------|
| `entity` | `Any` | `true` | An entity instance (loaded or a lazy reference). |  |

Uses the same rules as [EntityIsDirty](./EntityIsDirty.md). Returns the names in mapping order; associations and collections are reported by their property name.

## Examples

```java
user = entityLoadByPK( "User", 1 );
user.setEmail( "new@example.com" );
user.setRole( entityLoadByPK( "Role", 2 ) );
entityGetDirtyProperties( user );   // [ "email", "role" ]
```
