# Release History

In this section, you will find the release notes for each version we release under this major version. If you are looking for the release notes of previous major versions, use the version switcher at the top left of this documentation book. Here is a breakdown of our major version releases.

## v2.x

bx-orm 2 runs on Hibernate ORM 7.4. It adds fluent criteria queries, `orm.*` errors, a boot cache for fast production starts, entities as structs and much more.

* [What's New in 2.0.0](whats-new-2.0.0.md): the tour of new features.
* [Upgrading to 2.0.0](upgrading-to-2.0.0.md): the checklist to move a 1.x application.
* [2.x release notes](2x.md): every change, release by release.
